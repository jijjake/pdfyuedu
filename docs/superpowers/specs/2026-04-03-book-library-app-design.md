# 书库软件设计文档

## 1. 项目概述

本项目旨在开发一款跨平台的书库软件，用户可以导入书籍、保存到云端，并通过搜索功能快速找到书籍。软件将支持多种云存储服务，包括主流网盘、WebDAV和自建服务，以降低服务器成本。

### 1.1 核心功能

- **书籍管理**：导入、分类、标签管理
- **云存储同步**：支持主流网盘、WebDAV和自建服务
- **书籍搜索**：本地搜索和在线搜索
- **书籍信息自动收集**：从网上自动收集书籍元数据
- **自定义网站**：支持添加和管理自定义书籍下载网站
- **跨平台支持**：支持桌面端、移动端和Web端
- **内置阅读器**：支持PDF等格式的阅读

### 1.2 技术选型

- **开发框架**：Flutter（跨平台）
- **云存储集成**：统一云存储接口
- **书籍格式支持**：PDF、EPUB、MOBI等
- **数据库**：SQLite（本地）
- **状态管理**：Provider/Bloc

6. **设置模块**：负责用户配置和系统设置

## 3. 核心功能设计

### 3.1 书籍管理

- **书籍导入**：支持从本地文件系统导入书籍，支持拖放操作
- **书籍分类**：支持按类别、作者、出版社等分类
- **标签管理**：支持为书籍添加自定义标签
- **书籍详情**：显示书籍的封面、标题、作者、出版社、ISBN等信息
- **书籍状态**：支持标记阅读进度、收藏状态等

### 3.2 云存储同步

- **支持的服务**：
  - 主流网盘：百度网盘、Dropbox、Google Drive等
  - WebDAV服务：任何支持WebDAV协议的存储服务
  - 自建服务：Nextcloud、Synology NAS等
- **同步策略**：
  - 双向同步：本地和云端数据保持一致
  - 手动同步：用户可手动触发同步
  - 自动同步：可设置定时自动同步
- **同步内容**：书籍文件、元数据、阅读进度等

### 3.3 搜索功能

- **本地搜索**：基于书籍元数据的本地搜索
- **在线搜索**：支持从自定义网站搜索书籍
- **搜索结果**：显示书籍封面、标题、作者、简介等信息
- **搜索历史**：记录用户的搜索历史

### 3.4 书籍信息自动收集

- **元数据提取**：从书籍文件中提取元数据
- **封面获取**：从网上获取书籍封面
- **在线搜索**：通过ISBN、标题等信息从网上搜索书籍详情
- **信息存储**：将收集到的信息存储到本地数据库

### 3.5 自定义网站

- **网站管理**：支持添加、编辑、删除自定义网站
- **网站配置**：为每个网站配置搜索规则、下载规则等
- **网站分类**：支持对网站进行分类管理

### 3.6 内置阅读器

- **支持格式**：PDF、EPUB、MOBI等
- **阅读功能**：翻页、缩放、书签、注释等
- **阅读设置**：字体大小、背景颜色、亮度等
- **阅读进度**：自动保存阅读进度

## 4. 云存储集成方案

### 4.1 统一云存储接口

设计一个统一的云存储接口，支持不同云存储服务的接入：

```dart
abstract class CloudStorage {
  Future<void> authenticate();
  Future<List<File>> listFiles(String path);
  Future<void> uploadFile(String localPath, String remotePath);
  Future<void> downloadFile(String remotePath, String localPath);
  Future<void> deleteFile(String path);
  Future<bool> exists(String path);
}
```

### 4.2 具体实现

- **百度网盘**：使用百度网盘开放API
- **Dropbox**：使用Dropbox API
- **Google Drive**：使用Google Drive API
- **WebDAV**：使用WebDAV协议
- **Nextcloud**：使用Nextcloud API或WebDAV

## 5. 用户界面设计

### 5.1 主界面

- **布局**：采用网格或列表布局显示书籍封面
- **导航**：底部导航栏，包含书库、搜索、导入、设置等选项
- **筛选**：支持按类别、作者、标签等筛选书籍
- **排序**：支持按标题、作者、添加时间等排序

### 5.2 书籍详情页

- **信息展示**：显示书籍封面、标题、作者、出版社、ISBN、简介等信息
- **操作按钮**：阅读、编辑信息、删除、分享等

### 5.3 云存储设置

- **服务列表**：显示已添加的云存储服务
- **添加服务**：支持添加新的云存储服务
- **同步设置**：配置同步策略、同步路径等

### 5.4 搜索界面

- **搜索框**：支持输入关键词搜索
- **搜索选项**：支持选择搜索范围（本地、在线）
- **搜索结果**：显示搜索结果列表

### 5.5 导入界面

- **导入方式**：支持从本地文件系统导入、从云存储导入、从自定义网站下载导入
- **导入进度**：显示导入进度和状态

### 5.6 阅读器界面

- **阅读区域**：显示书籍内容
- **控制栏**：包含翻页、目录、设置等按钮
- **工具栏**：包含书签、注释、搜索等功能

### 5.7 设置界面

- **基本设置**：语言、主题、默认存储位置等
- **云存储设置**：管理云存储服务
- **自定义网站设置**：管理自定义网站
- **关于**：显示版本信息、版权信息等

## 7. 技术实现要点

### 7.1 跨平台实现

- 使用Flutter框架实现跨平台支持
- 使用平台特定代码处理平台差异
- 适配不同屏幕尺寸和分辨率

### 7.2 云存储集成

- 使用OAuth 2.0进行身份验证
- 实现文件上传、下载、同步等操作
- 处理网络错误和重试机制

### 7.3 书籍信息收集

- 使用正则表达式和XPath解析网页
- 使用ISBN API获取书籍信息
- 实现异步操作和缓存机制

### 7.4 性能优化

- 使用缓存减少网络请求
- 实现懒加载减少内存使用
- 优化数据库查询性能

### 7.5 安全性

- 加密存储敏感信息（如云存储凭证）
- 实现安全的网络请求
- 防止SQL注入等安全问题
