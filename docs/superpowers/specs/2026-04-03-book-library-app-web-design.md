# 书库软件Web版设计文档

## 1. 项目概述

本项目旨在开发一款基于Web的书库软件，用户可以导入书籍、管理书籍库、搜索书籍，并通过浏览器访问。软件将支持本地存储和云存储同步，以提供便捷的书籍管理体验。

### 1.1 核心功能

- **书籍管理**：导入、分类、标签管理
- **云存储同步**：支持WebDAV和主流云存储服务
- **书籍搜索**：本地搜索
- **书籍信息自动收集**：从网上自动收集书籍元数据
- **内置阅读器**：支持PDF等格式的阅读
- **响应式设计**：支持桌面端和移动端

### 1.2 技术选型

- **前端框架**：React + TypeScript
- **构建工具**：Vite
- **状态管理**：React Context API + useReducer
- **样式方案**：Tailwind CSS
- **本地存储**：IndexedDB (通过Dexie.js)
- **云存储集成**：WebDAV client
- **PDF阅读**：PDF.js
- **HTTP客户端**：Axios

## 2. 系统架构

### 2.1 总体架构

```
┌─────────────────┐
│   用户界面层   │
├─────────────────┤
│   业务逻辑层   │
├─────────────────┤
│  数据访问层    │
├─────────────────┤
│  存储层        │
└─────────────────┘
```

### 2.2 模块划分

1. **书籍管理模块**：负责书籍的导入、分类、标签管理等
2. **云存储模块**：负责与各种云存储服务的交互
3. **搜索模块**：负责书籍的本地搜索
4. **信息收集模块**：负责从网上自动收集书籍元数据
5. **阅读器模块**：负责书籍的阅读功能
6. **设置模块**：负责用户配置和系统设置

## 3. 核心功能设计

### 3.1 书籍管理

- **书籍导入**：支持从本地文件系统导入书籍
- **书籍分类**：支持按类别、作者、出版社等分类
- **标签管理**：支持为书籍添加自定义标签
- **书籍详情**：显示书籍的封面、标题、作者、出版社、ISBN等信息
- **书籍状态**：支持标记阅读进度、收藏状态等

### 3.2 云存储同步

- **支持的服务**：
  - WebDAV服务：任何支持WebDAV协议的存储服务
  - 主流云存储：通过WebDAV接口支持
- **同步策略**：
  - 手动同步：用户可手动触发同步
- **同步内容**：书籍元数据、阅读进度等

### 3.3 搜索功能

- **本地搜索**：基于书籍元数据的本地搜索
- **搜索结果**：显示书籍封面、标题、作者、简介等信息
- **搜索历史**：记录用户的搜索历史

### 3.4 书籍信息自动收集

- **元数据提取**：从书籍文件中提取元数据
- **封面获取**：从网上获取书籍封面
- **在线搜索**：通过ISBN、标题等信息从网上搜索书籍详情
- **信息存储**：将收集到的信息存储到本地数据库

### 3.5 内置阅读器

- **支持格式**：PDF
- **阅读功能**：翻页、缩放、书签、注释等
- **阅读设置**：字体大小、背景颜色、亮度等
- **阅读进度**：自动保存阅读进度

### 5.6 阅读器界面

## 6. 技术实现要点

### 6.1 前端实现

- 使用React + TypeScript实现前端界面
- 使用Tailwind CSS实现响应式设计
- 使用Vite作为构建工具
- 使用Dexie.js操作IndexedDB

### 6.2 云存储集成

- 使用webdav-client库实现WebDAV协议
- 实现基本的文件上传、下载、同步等操作
- 处理网络错误和重试机制

### 6.3 书籍信息收集

- 使用ISBN API获取书籍信息
- 实现异步操作和缓存机制

### 6.4 性能优化

- 使用React.memo和useMemo优化渲染性能
- 使用IndexedDB存储大量数据
- 实现图片懒加载

### 6.5 安全性

- 加密存储敏感信息（如云存储凭证）
- 实现安全的网络请求
